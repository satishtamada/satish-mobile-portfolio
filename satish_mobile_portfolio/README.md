# Tamada Satish Kumar — Mobile Developer Portfolio

A responsive, static portfolio website for a Senior Mobile Application Developer specializing in Android/Kotlin and Flutter.

## Before publishing

1. Add your current resume PDF at `assets/Tamada-Satish-Kumar-Resume.pdf`.
2. Open `script.js` and set your professional email.
3. Optionally add your LinkedIn and GitHub profile URLs in `script.js`.
4. Review every skills and project statement. Remove anything you cannot confidently discuss or are not permitted to disclose.
5. Replace generic project case studies with verified responsibilities, technologies, and outcomes. Do not add confidential source code, API keys, patient information, internal screenshots, or proprietary details.
6. Open `index.html` locally and test the navigation and resume link.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new public repository named `satish-mobile-portfolio` (or another name you prefer).
2. Upload the contents of this folder to the repository root. The root should contain `index.html`, `styles.css`, `script.js`, and the `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to finish publishing. The URL will normally look like `https://YOUR-GITHUB-USERNAME.github.io/satish-mobile-portfolio/`.
7. Open the URL and verify the site, resume download, and contact links. Share only after this verification.

If you use a different repository name, the URL path will use that name. A user/organization site repository named `YOUR-GITHUB-USERNAME.github.io` instead publishes at the root domain.

## Resume file

The download link expects this exact path:
`assets/Tamada-Satish-Kumar-Resume.pdf`

If you choose a different filename, update the `href` in `index.html`.

## Local preview

You can open `index.html` in a modern browser. No build step or package manager is required.

## Customization

- Main content and sections: `index.html`
- Colors and responsive layout: `styles.css`
- Contact links and mobile navigation: `script.js`

## Important

This is a static starter portfolio. It is not live until you publish it through GitHub Pages or another host. Project visuals are CSS illustrations, not actual screenshots of employer applications. Project write-ups are intentionally generic placeholders until you verify and personalize them.
